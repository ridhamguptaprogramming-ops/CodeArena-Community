# CodeArena — Frequently Asked Questions

## What is CodeArena?

CodeArena is an online coding and assessment platform designed for students, teachers, and developers. It provides a coding environment where users can write, run, test, and submit programs.

## Which programming languages are supported?

CodeArena supports:

- Java
- Python 3
- JavaScript
- C++
- C

Additional languages may be added in future releases.

## Who can use CodeArena?

CodeArena is designed for:

- Students
- Teachers
- Coding learners
- Developers
- Competitive programmers

## Can I run my code online?

Yes. CodeArena is designed to execute submitted programs through a secure code-execution environment.

## Can I provide custom input?

Yes. Users can provide input through the Standard Input panel before running their program.

## How does code execution work?

The general execution flow is:

```text
Code Editor
    ↓
CodeArena API
    ↓
Execution Service
    ↓
Secure Sandbox
    ↓
Compiler / Runtime
    ↓
Output
```
