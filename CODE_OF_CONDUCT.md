# CodeArena — Reporting Guidelines

## Reporting a Code of Conduct Violation

If you experience or witness harassment, abusive behavior, discrimination, or other unacceptable behavior within the CodeArena community, please report it to the project maintainers.

### How to Report

Send an email to:

**[ridhamgupta020@gmail.com](mailto:ridhamgupta020@gmail.com)**

Please include:

- A brief description of what happened
- Date and approximate time of the incident
- GitHub issue, pull request, or discussion link if applicable
- Names or usernames of people involved
- Screenshots or other relevant information, if available

### Confidentiality

Reports will be handled respectfully and information will only be shared when necessary to review and address the report.

### What Happens After a Report?

The CodeArena maintainers will:

1. Review the report.
2. Request additional information if necessary.
3. Determine whether the Code of Conduct was violated.
4. Take appropriate action when required.
5. Follow up with the reporter when appropriate.

### Retaliation

Retaliation against someone who makes a report in good faith is not acceptable.
